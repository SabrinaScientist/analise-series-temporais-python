# Análise de Séries Temporais com Python e ML

## 🎯 Objetivo
Este projeto analisa variáveis elétricas industriais (Tensão, Corrente e Potência) coletadas ao longo de 3 anos. O objetivo principal é identificar padrões de consumo e treinar um modelo de Regressão Linear Simples para prever a Potência (W) a partir da Corrente (A).

## 🛠️ Tecnologias Utilizadas
* Python (Pandas, NumPy)
* Matplotlib e Seaborn (Visualização de Dados)
* Scikit-Learn (Machine Learning)

## 📊 Principais Resultados
* O modelo preditivo alcançou um **R² de 81,18%** e um erro médio (RMSE) de apenas 50.79 W.
* Foi comprovada a relação linear positiva direta entre corrente e potência.
* Os dados foram limpos, normalizados (Min-Max) e padronizados (Z-Score) para garantir a estabilidade do algoritmo.
